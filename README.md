# Dokumentacja projektu inżynierskiego

## Temat projektu
**Prototyp bezpiecznego systemu skrytek pocztowych i ewaluacja jego podatności z zastosowaniem metodyki RedTeam vs BlueTeam**

## Opis projektu
Celem projektu jest opracowanie prototypu systemu skrytek pocztowych wykorzystującego rozwiązania IoT oraz przeprowadzenie analizy jego bezpieczeństwa z perspektywy zespołów RedTeam i BlueTeam.

Projekt obejmuje przygotowanie infrastruktury sprzętowej i sieciowej, opracowanie oprogramowania obsługującego system oraz testowanie zastosowanych mechanizmów bezpieczeństwa.

## Cel repozytorium
Repozytorium służy do przechowywania i wersjonowania dokumentacji związanej z realizacją projektu inżynierskiego, w tym:
- schematów infrastruktury systemu,
- dokumentacji konfiguracji urządzeń,
- wyników testów i zrzutów ekranu,
- materiałów potwierdzających postęp prac,
- dokumentacji technicznej projektu.
